⚡ Атмосферная случайность

RANDOM.ORG получает случайные значения из атмосферного радиошума. В этот физический шум вносит вклад естественная электрическая активность атмосферы.

CloudByAlex обращается к RANDOM.ORG через серверный Cloudflare Worker, чтобы браузер мог использовать этот источник без раскрытия серверных данных доступа.

🔐 Безопасная случайность браузера

Современные браузеры предоставляют Web Crypto API. Функция crypto.getRandomValues() предназначена для криптографически стойких псевдослучайных значений и значительно лучше подходит для таких задач, чем обычный Math.random().

Этот режим работает локально на вашем устройстве и не требует сетевого запроса.

🎲 Для чего использовать?

Выберите победителя, бросьте кубик, подбросьте монету, выберите ресторан, случайного участника команды, создайте тестовые данные или просто примите нейтральное решение.

⚠️ Не для регулируемых азартных игр

Этот бесплатный инструмент предназначен для обычной рандомизации и экспериментов. Для регулируемых розыгрышей и других высокорисковых задач нужны специализированные системы и соответствующий контроль.

Как работает генератор случайных чисел

По умолчанию CloudByAlex не использует простой Math.random(). Режим «Безопасный браузер» получает 32-битные криптографические случайные значения через Web Crypto API, а затем переводит их в заданный вами диапазон методом rejection sampling. Такой подход избегает простой ошибки modulo bias, которая может появляться, если механически брать остаток от деления случайного числа на размер диапазона.

Случайное число в своём диапазоне

Укажите целые минимум и максимум, а затем количество результатов. Можно быстро выбрать диапазоны 1–10, 1–100 и 1–1000. Поддерживаются и отрицательные числа в пределах ограничений формы.

Случайный выбор из списка

Откройте «Выбор из списка» и добавьте по одному варианту на строку. Генератор случайно выбирает индекс с помощью выбранного источника и возвращает соответствующее имя, ресторан, задачу, участника или другой пункт.

Кубик и монета

Режим кубика генерирует целое число от 1 до 6. Монета выбирает один из двух исходов — «ОРЁЛ» или «РЕШКА». Оба режима используют тот же источник случайности, который вы выбрали выше.

Псевдослучайность и физическая случайность

Криптографическая псевдослучайность создаётся безопасным алгоритмом с системной энтропией и подходит для множества программных задач. Атмосферный режим вместо этого запрашивает значения RANDOM.ORG, полученные из измерений физического шумового источника.

О приватности: в режиме «Безопасный браузер» результат создаётся локально. Текст из «Выбора из списка» никуда не отправляется. В атмосферном режиме Worker получает только числовой диапазон, необходимый для случайного запроса.

Частые вопросы о генераторе

Насколько безопасен этот генератор случайных чисел?

Режим «Безопасный браузер» использует crypto.getRandomValues() из Web Crypto API. Эта функция предназначена для криптографически стойкой псевдослучайности и является более сильным источником, чем обычный Math.random().

Что такое атмосферная случайность?

Дополнительный режим запрашивает значения у RANDOM.ORG, который получает случайность из атмосферного радиошума. CloudByAlex передаёт числовой запрос через Cloudflare Worker.

Можно ли сгенерировать несколько чисел сразу?

Да. Укажите минимум, максимум и количество. В этой версии интерфейса можно получить до 20 значений за один запуск.

Можно ли выбрать случайное имя из списка?

Да. Откройте «Выбор из списка», добавьте по одному варианту на строку и нажмите «Сгенерировать». Выбранный пункт появится справа и попадёт в историю последних результатов.

Это то же самое, что Math.random()?

Нет. Безопасный режим использует Web Crypto API вместо Math.random(). Web Crypto разработан для задач, где качество случайности важнее, чем в обычной псевдослучайной функции JavaScript.

Можно ли использовать это для официальной лотереи?

Инструмент не сертифицирован для регулируемых азартных игр, официальных лотерей или других высокорисковых розыгрышей. Для таких задач нужны специализированные системы, аудит и необходимые юридические разрешения.
